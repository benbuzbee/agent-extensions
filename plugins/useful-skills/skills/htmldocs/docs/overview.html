Overview

htmldocs maintains and creates HTML-based documentation — issue logs, architecture specs, handoffs, runbooks — so files read well for humans and parse predictably for downstream agents. The DOM is the workspace: elements are addressable units, data-* attributes carry state, and structure itself is the index.

Triggered by phrasings like "update the docs" in repos whose documentation folder is HTML-based. Triggers, workflow, and principles are canonical in SKILL.md — this page is the entry point, not the source.

Where the detail lives

Canonical content lives one click away. This page links rather than restates — the same rule the skill itself enforces:
