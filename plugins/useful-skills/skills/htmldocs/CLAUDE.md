# htmldocs

HTMLDocs is a skill for agents to write, maintain, and use HTML documentation.

HTML documents are excellent for achieving AI alignment and creating durable memory of product requirements, architecture, and more.

It is inspired by [The Unreasonable Effectiveness of HTML](https://claude.com/blog/using-claude-code-the-unreasonable-effectiveness-of-html)

## HTML Documentation

The skill contains its own documentation in docs describing the skill, architecture, design choices, etc. Consult the documentation and keep it up to date.

## Review

The skill includes support for a review system whereby the agent can present the HTML Doc through a local server, and the user can then review the document with the agent.

## Distribution

The skill checks in everything to be distributed including a compiled .mjs files. It's not elegant, but it works for now!
