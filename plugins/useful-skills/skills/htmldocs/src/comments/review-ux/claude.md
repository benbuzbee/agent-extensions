Everything here must be implementable in every environment the review UI runs in — the browser widget under the local Node server and the hosted Cloudflare Worker alike. That portability is the contract: this layer stays independent of transport, fs, server, GitHub, Cloudflare, and D1, and it neither constructs a store nor mints identity — the store and author arrive through MountDeps. The inject.ts helpers produce the markup strings; adapters supply only the placement mechanism.
