Everything here must be implementable in every environment the review UI runs in — the browser widget under the local Node server and the hosted Cloudflare Worker alike. That portability is the contract: this layer stays independent of transport, fs, server, GitHub, Cloudflare, and D1, and it neither constructs a store nor mints identity — the store and author arrive through MountDeps. `types.ts` carries NO legacy shape — the seed and the GET `?comments` response are the internal `{ threads }` view (`CommentsSeed`); the legacy `*.comments.json` (de)serialization lives only in the Node disk layer (`adapters/local/legacy-format.ts`). The inject.ts helpers produce the markup strings; adapters supply only the placement mechanism.
